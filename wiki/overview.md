## 목적

이 볼트는 4개 영역을 통합하는 영속적 지식 베이스입니다:

1. **풀스택 개발** — 본인 코드, 프로젝트, 아키텍처 결정
2. **AI 논문 리서치** — 논문 요약, 방법론 비교, 핵심 주장
3. **취업시장 분석** — 회사, JD, 연봉, 스택 트렌드
4. **개발 노트** — 학습 내용, 강의 시사점, 실무 적용

각 영역은 독립된 도메인 허브를 가지지만, **공유 개념 풀**(`wiki/concepts/`)과 **공유 엔티티 풀**(`wiki/entities/`)을 통해 크로스 도메인 연결이 자동으로 생겨납니다.

예를 들어:
- AI 논문에서 배운 "Retrieval-Augmented Generation" 개념 → 본인 풀스택 프로젝트에 적용 → 프로젝트 페이지와 논문 페이지가 같은 개념 페이지를 참조
- 취업시장에서 "React 요구 회사 많음" → 개발 노트에서 React 학습 → 양쪽이 `[[React]]` 엔티티 페이지로 연결

## 4개 도메인 한눈에

### 풀스택 개발 ([[fullstack-dev]])
**폴더**: `wiki/projects/`, `wiki/decisions/`
**타겟 콘텐츠**: 본인 Git 저장소 README, ADR, 아키텍처 다이어그램, 코드 스니펫

### AI 논문 리서치 ([[ai-research]])
**폴더**: `wiki/papers/`
**타겟 콘텐츠**: arXiv 논문 PDF, 저자 블로그, 구현 코드

### 취업시장 분석 ([[job-market]])
**폴더**: `wiki/companies/`
**타겟 콘텐츠**: JD, 회사 기술 블로그, 연봉 리포트, 인터뷰 후기

### 개발 노트 ([[dev-notes]])
**폴더**: `wiki/learning/`
**타겟 콘텐츠**: 유튜브 트랜스크립트, 강의 노트, 튜토리얼 마크다운

## 사용법 요약

```
1. .raw/<카테고리>/ 에 소스 떨어뜨림
2. Claude에게 "ingest [파일명]"
3. Claude가 8~15개 페이지 생성/갱신
4. "query: ..." 또는 자연어로 질문
5. 10~20회 인제스트마다 "lint the wiki"
```

자세한 스키마는 루트의 [WIKI.md](../WIKI.md) 참조.

## 핵심 원칙

- **지식은 복리로 쌓입니다.** 모든 소스는 기존 8~15개 페이지를 풍부하게 만듭니다.
- **핫 캐시가 증폭기.** `hot.md` 약 500단어가 매 세션을 최신 컨텍스트에서 시작하게 해줍니다.
- **Obsidian은 IDE, Claude는 프로그래머.** 사람은 소스 큐레이팅과 질문, Claude는 모든 쓰기와 유지.
